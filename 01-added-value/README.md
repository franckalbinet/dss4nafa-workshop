# Session 1: DSS4NAFA added value

Speaker: Lazar Adjigogov. 30 minutes.

How DSS4NAFA supports a response from the sampling plan to the laboratory results. The ASTA module selects sampling areas from land use maps, crop calendars and exclusion zones. Sample collectors and laboratories register samples with the mobile app. The Nudge module imports data collected earlier or by hand. The example input files are in [data](../data/).
